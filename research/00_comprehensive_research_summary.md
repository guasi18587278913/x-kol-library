## 一、项目概览

### 产品定位
基于 James AI 的思路，打造一个「X 大佬电子阅览室」，实现两大核心功能：
1. **内容浏览** - 按类目浏览 KOL 及其历史推文
2. **AI 对话** - 与基于推文内容的 AI Agent 交流

### 类目体系
共 88 个独立类目，覆盖 8 大领域：
- AI 技术（15 个子类目）
- 创业出海（12 个子类目）
- 商业财富（10 个子类目）
- 营销增长（15 个子类目）
- 设计产品（10 个子类目）
- 投资理财（8 个子类目）
- 内容创作（8 个子类目）
- 效率认知（10 个子类目）

## 二、KOL 筛选标准（已完成）

### 最低准入门槛
| 指标 | 最低要求 |
|------|---------|
| 粉丝数 | ≥ 5,000（推荐 ≥ 10,000）|
| 互动率 | ≥ 1%（按粉丝数计算）|
| 月均发推量 | ≥ 10 条 |
| 最近活跃时间 | 7 天内有发推 |
| 原创内容占比 | ≥ 50% |
| 领域内容占比 | ≥ 60% |
| 账号存续时间 | ≥ 6 个月 |

### KOL 分级体系
- **Nano** (1K-10K): 互动率 ~16.65%
- **Micro** (10K-100K): 互动率 ~7.3%（最佳 ROI）
- **Macro** (100K-1M): 互动率 ~1-3%
- **Mega** (1M+): 互动率 < 1%

### 综合评分权重
- 互动率：25%
- 内容质量：25%
- 垂直度：20%
- 粉丝基数：15%
- 活跃度：15%

## 三、内容抓取技术方案（已完成）

### MVP 阶段推荐方案
**MCP 工具 + twikit**
- 成本：~$13/月（100 个 KOL）
- 适用场景：初期验证，数据量 < 500 KOL
- 优势：开发成本低，快速启动

### 增长阶段方案
**TwitterAPI.io**
- 成本：$0.15/1000 条推文，约 $19/月
- 适用场景：用户量增长，需要稳定服务
- 优势：官方级可靠性，95% 配额节省（增量更新）

### 数据库设计
PostgreSQL + JSONB 存储结构：
- `kols` 表 - KOL 基础信息
- `tweets` 表 - 推文内容
- `tweet_metrics` 表 - 互动数据（点赞/转发/评论）
- `scrape_state` 表 - 抓取状态跟踪

### 更新策略
- 活跃账号（日均 ≥ 5 条）：每 1 小时
- 普通账号（日均 2-5 条）：每 6 小时
- 低频账号（日均 < 2 条）：每 12 小时
- 使用 `since_id` 实现增量抓取，节省 95% API 配额

## 六、技术架构建议

### 前端展示
- 首页：88 个类目卡片展示，按 8 大领域分组
- 类目页：该类目下所有 KOL 列表（头像 + 简介 + 粉丝数）
- KOL 详情页：个人简介 + 历史推文时间线
- AI 对话页：基于该 KOL 推文内容的 Agent 对话界面

### 后端服务
- **数据抓取服务**：定时任务，按活跃度分级抓取
- **数据存储**：PostgreSQL + JSONB
- **AI Agent 服务**：基于 LangChain/LlamaIndex 的 RAG 实现
  - 向量化存储：KOL 推文内容
  - 检索增强：根据用户问题检索相关推文
  - 生成回复：模拟 KOL 风格回答

### MVP 开发优先级
1. **阶段一**：静态展示（类目 + KOL 列表 + 推文展示）
2. **阶段二**：数据抓取（接入 MCP/twikit，定时更新）
3. **阶段三**：AI 对话（RAG Agent 实现）

## 七、关键发现与建议

### 7.1 KOL 筛选建议
- **优先 Micro 级别**（10K-100K 粉丝）：互动率最高（~7.3%），内容质量好
- **垂直度 > 粉丝数**：宁要 10K 粉丝的垂直大佬，不要 100K 泛娱乐网红
- **中文内容为主**：目标用户是中文用户，优先中文 KOL

### 7.2 技术方案建议
- **MVP 阶段**：用 MCP 工具手动收集 50-100 个核心 KOL，快速验证产品
- **增长阶段**：切换到 TwitterAPI.io，实现自动化抓取和更新
- **成本控制**：增量更新机制必须实现，节省 95% API 配额

### 7.3 内容策略建议
- **质量 > 数量**：每个类目精选 5-10 个顶级 KOL，而非堆砌几十个平庸账号
- **动态更新**：新晋黑马及时补充，僵尸账号及时剔除
- **用户贡献**：开放推荐通道，让用户提名优质 KOL
